# Pebble Sort: a counter or a clock

Motivator: Submission. Author: rajvardhan19.

## Mechanic

Sort 30 pebbles (● ▲ ■) into matching bowls: tap a bowl or press **1**, **2**, **3**. A wrong bowl hands the pebble back, so nothing is lost; the round ends when the basket is empty.

The toggle, **Move counter in place of a clock**, starts on: the game counts moves and never times you. Turn it off and a 20-second clock can end the round with pebbles left.

## Dynamic

One playtester sorted with the counter on and with the clock. With the counter, they treated it as a game to unwind with; with the clock, as a speedrun worth comparing with friends. I expected the clock to pull the game toward Challenge's time pressure; it went further, toward Competition, where friends end up "one-upping each other by winning more points and prizes" (Schell 2019, p. 157).

## Aesthetic

They called the game "relaxing" and "low stress," something they would play "to relax my mind": Submission as "game as pastime" (Hunicke et al. 2004, p. 2). The clock "does add some urgency," they said, which is fun when comparing speedruns with friends.
